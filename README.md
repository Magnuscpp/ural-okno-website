# Урал Окно — Окна, двери, балконы, натяжные потолки, ворота и заборы

Официальный сайт-витрина компании **«Урал Окно»** (г. Коркино).

Сайт выполнен в современном светлом дизайне: адаптивный плавающий навбар, контрастный Hero-экран, интерактивный каталог продукции с фильтрацией по категориям, подробный блок офисов с графиком работы, реальные юридические документы (соответствие 152-ФЗ) и прямая связь через телефон и ВКонтакте.

---

## 🪟 Услуги и каталог продукции

- **Пластиковые окна** — классические и энергосберегающие стеклопакеты (Rehau, Veka, Axor, Roto)
- **Балконы и лоджии** — теплое и холодное раздвижное остекление (Provedal, панорамные конструкции)
- **Входные двери** — стальные бронированные двери с терморазрывом и защитой 4 класса
- **Межкомнатные двери** — массив, натуральный шпон, эмаль, бесшумные магнитные замки
- **Натяжные потолки** — матовые, сатиновые, глянец, теневой профиль EuroKRAAB, световые линии
- **Ворота** — гаражные секционные и въездные с надежной автоматикой (DoorHan, Alutech)
- **Заборы и ограждения** — евроштакетник и профнастил Grand Line с антикоррозийной защитой

## 🚀 Запуск и деплой

### Локально:
Просто откройте файл `index.html` двойным кликом в любом браузере.

### Бесплатный хостинг на GitHub Pages:
1. Загрузите файлы в публичный репозиторий GitHub.
2. В репозитории откройте **Settings** → **Pages**.
3. В **Source** укажите `Deploy from a branch`, выберите ветку `main` и директорию `/(root)`.
4. Сохраните — сайт станет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
